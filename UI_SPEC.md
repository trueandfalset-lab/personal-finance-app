# UI SPECIFICATION

## Design Principles
- Simple
- One-hand usable
- Minimal text
- Offline first
- Fast loading

## App Start Flow
PIN Screen → Dashboard

## PIN SCREEN
Elements:
- App Name
- PIN Input (4 digit)
- Unlock Button

Actions:
- Correct PIN → Dashboard
- Wrong PIN → Error message

## DASHBOARD SCREEN
Top Section:
- Total Net Worth (Large)
- Credit Score (Card)

Summary Cards:
- Total Bank Balance
- Total Loan Remaining
- Total Assets Value

Bottom:
- Last Updated Date

Floating Action Button (+):
- Add Bank
- Add Loan
- Add Asset
- Add Business
- Add Investment
- Add Cash

Bottom Navigation:
- Home
- Accounts
- Loans
- Assets
- More

## BANK ACCOUNTS SCREEN
List View:
- Bank Name
- Account Type
- Balance
- Last Updated

Actions:
- Tap → Edit
- Swipe → Delete

## ADD / EDIT BANK SCREEN
Fields:
- Bank Name
- Account Type
- Balance
- Notes

Buttons:
- Save
- Cancel

## LOANS SCREEN
List:
- Loan Name
- EMI Amount
- Due Date
- Remaining Amount
- Status Color

Actions:
- Mark EMI Paid
- Edit Loan

## ASSETS SCREEN
Tabs:
- Cash
- Jewellery
- Property / Vehicle

## BUSINESS / FARM SCREEN
Fields:
- Name
- Category
- Current Value
- Monthly Profit
- Notes

## INVESTMENTS SCREEN
Tabs:
- FD / RD
- Mutual Fund
- Stocks
- Digital Gold
- Other

## MORE SCREEN
- Credit Score Details
- Security Settings
- Backup / Export
- About App

## COLORS
- Primary: Dark Blue
- Accent: Green
- Warning: Red
- Background: Light Grey
